# نقاط التكامل — FRATY AI

يوفّر المشروع مسارًا للمحادثة وتوليد مشروع Android بصيغة ZIP. يوجد مهايئ صور لكنه غير مفعّل في إعداد Gemini المجاني، كما أن الفيديو والصوت الحي وتسجيل Google وبناء APK آليًا تحتاج مزوّدات وخدمات إضافية. مفاتيح الخدمات تبقى في الخادم، ولا تُضمَّن داخل APK.

## المحادثة المتاحة عند الإعداد

اضبط متغيرات البيئة على الخادم: `APP_ACCESS_TOKEN` رمز وصول للتطبيق، و`GEMINI_API_KEY` مفتاح Gemini اختياريًا بدل `OPENAI_API_KEY`، و`OPENAI_MODEL` اسم النموذج. الإعداد المجاني الحالي للمحادثة هو `OPENAI_BASE_URL=https://generativelanguage.googleapis.com/v1beta/openai/` و`OPENAI_MODEL=gemini-3.5-flash-lite`. مفتاح Gemini يبقى في أسرار الخادم فقط. Free tier له حصص وحدود وقد تستخدم Google مدخلات الطلبات لتحسين منتجاتها؛ راجع شروط Google قبل الاستخدام.

يرسل التطبيق `POST /api/v1/chat` مع الرسائل و`X-App-Token`. يتحقق الخادم من الرمز وحجم المدخلات وحدّ الطلبات، ثم يمرر المحادثة إلى واجهة متوافقة مع OpenAI ويعيد نص ردّ النموذج. يجب التأكد من توافق API المزود والنموذج قبل النشر. مسار `GET /api/v1/integrations` يعرض ما تم ضبطه.

## إنشاء مشروع Android بصيغة ZIP

يرسل وضع «إنشاء تطبيق» `POST /api/v1/projects` مع `{ "prompt": "..." }`. يحوّل Gemini الوصف أو الكود الملصق إلى نموذج تطبيق Kotlin وJetpack Compose داخل قالب Android Studio ثابت، ثم يعيد رابط ZIP موقّعًا ومؤقتًا. هذا **مشروع مصدر وليس APK**: لا ينفّذ الخادم Gradle ولا يوقّع APK. نزّل الملف وافتحه في Android Studio لمراجعته وبنائه، وتحقق من الكود الناتج قبل تثبيته. الرابط ينتهي وفق `MEDIA_TTL_SECONDS`، وملفات Render المجانية مؤقتة.

## نقاط تحتاج تنفيذًا قبل تفعيلها

- **Google/Firebase:** إنشاء Firebase project وتسجيل Android package `com.fraty.ai` وبصمات SHA وإضافة `google-services.json`، ثم Credential Manager/Firebase Auth والتحقق من Firebase ID Token على كل مسار خاص.
- **الصوت الفوري:** اختيار مزود، إصدار بيانات وصول قصيرة العمر من الخادم، بث ثنائي الاتجاه وإيقاف/مقاطعة الجلسة وإدارة دورة حياة Android. الموجود حاليًا إملاء نظامي لإدخال النص فقط، وليس محادثة صوتية حية.
- **مشاركة الشاشة:** موافقة MediaProjection ظاهرة، foreground service بإشعار دائم وزر إيقاف، حدود لمعدل/حجم الإطارات، نقل آمن، وتحليل رؤية في الخادم. التطبيق لا يلتقط الشاشة الآن.
- **الصور:** يوجد adapter لـ `POST /api/v1/images` باستخدام OpenAI Images API أو endpoint متوافق معه. اضبط `IMAGE_API_KEY` و`IMAGE_MODEL`؛ يمكن استخدام `OPENAI_API_KEY` و`OPENAI_IMAGE_MODEL` بدل إعدادات المفتاح/النموذج المنفصلة. يحتاج الخادم عنوانًا عامًا عبر HTTPS؛ يستخدم Render المتغير `RENDER_EXTERNAL_URL` تلقائيًا، وعلى الاستضافات الأخرى اضبط `PUBLIC_BASE_URL`. يحفظ الخادم الصورة محليًا مؤقتًا ويعيد رابطًا موقّعًا صالحًا لمدة `MEDIA_TTL_SECONDS`.
- **الفيديو:** ما زال يحتاج اختيار مزوّد فيديو وتنفيذ عقده غير المتزامن (إنشاء مهمة، استعلام الحالة، تنزيل الناتج). `POST /api/v1/videos` يعيد HTTP 503 برسالة إعداد واضحة إلى حين اختيار المزوّد؛ لا ينتج فيديو وهميًا.
- **الملفات والمشاريع:** توليد مشروع مصدر ZIP متاح عبر `/api/v1/projects`. رفع ملفات المستخدم، الفحص الأمني، وبناء APK آليًا يحتاج عاملًا معزولًا وخدمة تخزين؛ بناء APK غير مفعّل.

## نشر آمن

يوجد مسار Render مجاني في `render.yaml` ودليله `DEPLOYMENT_RENDER_AR.md`. الخادم ينام بعد الخمول وملفاته مؤقتة، لذا يصلح للاختبار الشخصي فقط. الرمز الثابت داخل APK قابل للاستخراج؛ لا توزّع APK للعامة قبل إضافة مصادقة مستخدم حقيقية وحدود استخدام ومراقبة.
